# 🏎️ Elite Motors — Luxury Car Dealership & Listing Platform

**Elite Motors** is a modern, high-performance web application designed for luxury car dealerships and vehicle listing platforms. Built with **React 19**, **Vite 6**, and **Tailwind CSS**, it delivers a premium, fast, and responsive user experience for browsing, comparing, and inquiring about luxury and supercar inventory.
**Check Live URL : (https://elitemotors.jp/) 
---

## ✨ Project Highlights & Features

- 🚘 **Luxury Inventory Showcase**: Interactive car cards with high-resolution image galleries, detailed specifications (engine, horsepower, 0-60 mph acceleration, top speed), and feature badges.
- 🔊 **Synthesized Engine Sound FX**: Real-time Web Audio engine rev sound generator allowing users to experience the engine sound of featured performance cars.
- 🔍 **Dynamic Search & Filtering Engine**: Instant multi-parameter filtering by brand, body style (SUV, Sedan, Coupe, Convertible), price range, and transmission type.
- 🧮 **Interactive Financing & Loan Calculator**: Real-time monthly payment estimator with customizable down payment, interest rate, and loan term sliders.
- ⚖️ **Side-by-Side Vehicle Comparison**: Specs comparison modal enabling clients to compare performance metrics across multiple vehicles simultaneously.
- 💬 **VIP Concierge Assistant**: Interactive concierge widget for test drive requests, instant messaging, and bespoke client inquiries.
- 🌐 **Multi-Language Support**: Built-in internationalization supporting English, Spanish, French, and German.
- 🌓 **Adaptive Dark / Light Theme**: Designed with a sleek dark luxury theme alongside a full-contrast light mode toggle.
- 📱 **Fully Responsive Architecture**: Optimized for flawless display across mobile (375px+), tablet, and desktop devices.

---

## 🛠️ Technology Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: Tailwind CSS & Custom CSS Token System
- **Component Primitives**: Radix UI Tabs
- **Iconography & Visuals**: [Lucide React](https://lucide.dev/), Canvas Confetti
- **Audio System**: Web Audio API (Synthesized engine rev audio)

---

## 📁 Architecture Overview

- **`src/components/`**: Modular UI components (Car Cards, Search Filters, Financing Calculator, Concierge Assistant, Comparison Modal).
- **`src/data/`**: Centralized vehicle inventory dataset and metadata.
- **`src/utils/`**: Utility modules including engine audio synthesizer, currency converters, and translation dictionaries.
- **`public/assets/`**: Optimized imagery, logos, and branding assets.
